# 📚 AI Knowledge Assistant

An AI-powered PDF question-answering application built using Python, Streamlit, and Google Gemini.

Upload PDF documents and ask questions to receive AI-generated answers based on their content.

## 🚀 Features

- Upload multiple PDF documents
- Extract text from PDF files
- Ask questions about uploaded documents
- Generate AI-powered answers using Gemini
- Interactive Streamlit interface

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- PyPDF
- Python dotenv

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Mounish-SDE/AI-Knowledge-Assistant.git
cd AI-Knowledge-Assistant
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
GOOGLE_API_KEY=your_gemini_api_key
```

Run the application:

```bash
streamlit run app.py
```

## 💡 How to Use

1. Upload your PDF documents.
2. Enter a question about the documents.
3. Click Generate Answer.
4. Read the AI-generated response.

## 🔐 Security

Never share your Gemini API key.

Keep your `.env` file private.
